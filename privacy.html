Privacy Policy

1. Information Go Steko LLC Collects

Go Steko LLC does not collect any information on its servers or from third-party services. The App does not require an account, does not use Google Sign-In, and does not transmit personal information to Go Steko LLC, Rork, Supabase, or Google. After the user has explicitly accepted the Privacy Policy and Terms of Service within the App, the following types of information are stored locally on the user's device:

  • User-created content: Summits (goals), habits (objectives), checkpoints, progress logs, selected values, and settings that the user creates within the App.
  • Notification preferences: Notification settings, a chosen reminder time, and reminder scheduling data, if the user explicitly enables daily reminders. Reminders are disabled by default.
  • Locally stored data: All user-created content and settings are stored locally on the user's device to enable offline access. On web browsers, this data is stored in the browser's localStorage/IndexedDB area, which is not encrypted and may be accessible to other applications or browser extensions that have access to the user's device.
  • Consent record: A local flag indicating that the user has accepted the Privacy Policy and Terms of Service is stored on the device so the App does not ask for consent again on every launch.
  • Export files: When the user chooses to export data, the App creates a JSON file containing the user's local content and settings. The user controls where that file is saved and is responsible for its security.

2. How Go Steko LLC Uses Information

Because the App stores data locally on the user's device, Go Steko LLC does not process user data on its own servers. The App uses locally stored information to:

  • Display and organize user-created content and settings within the App.
  • Send notification reminders, if the user has enabled them.
  • Store user content locally on the user's device so the App functions offline.
  • Allow the user to export their data to a JSON file and import data from a JSON file the user previously exported.
  • Cache App files (such as HTML, JavaScript, and images) on the user's device using a service worker, which runs in the background of the user's web browser after the user has consented to enable faster loading and offline use. The service worker does not cache personal data and does not register until the user has accepted the Privacy Policy and Terms of Service.

Go Steko LLC does not sell personal information to third parties. Go Steko LLC does not have access to user data stored on the user's device unless the user voluntarily exports and sends a file to Go Steko LLC.

3. Data Storage and Protection

The App stores all user-created content and settings locally on the user's device. No user data is stored in a cloud database operated by Go Steko LLC or Supabase. The App does not require an internet connection to create, view, edit, or delete user content.

On web browsers, local data is stored in the browser's localStorage/IndexedDB area. Local browser storage is not encrypted and may be accessible to other applications or browser extensions that have access to the user's device. Users concerned about data security on web should clear browser data after each session or use the App's "Reset All Data" feature.

The App uses a service worker — a background script registered in the user's web browser — to cache App files (HTML, JavaScript, images) on the user's device. This caching enables faster loading and offline functionality. The service worker does not cache personal data; it caches only the App's software files. The service worker does not register and no caching occurs until the user has accepted the Privacy Policy and Terms of Service.

No method of electronic storage is completely secure. Go Steko LLC does not guarantee absolute security protection against unauthorized access, data breaches, or security incidents on the user's device.

4. Data Breach Notification

Because the App stores data locally on the user's device and does not transmit personal information to Go Steko LLC's servers, Go Steko LLC does not control or monitor user data. If Go Steko LLC becomes aware of a security issue affecting the App's software or hosting, Go Steko LLC will post information about the issue on the App's website or update this Privacy Policy when practicable. Users are responsible for protecting their own devices and exported data files.

6. Data Retention and Deletion

The App does not create user accounts. To clear local data, users should use the "Reset All Data" option in the App's Settings. This is the primary and recommended method for deleting locally stored data. When a user resets all data through the App, the following is deleted from the user's device:

  • User-created content, including summits, habits, checkpoints, progress logs, selected values, and settings.
  • Notification preferences and reminder settings.
  • The locally stored consent record indicating acceptance of the Privacy Policy and Terms of Service.

The following may remain on the user's device after a reset and can be cleared separately:

  • Cached App files stored by the service worker. These can be cleared by clearing the browser's site data or browsing data.
  • Any data export files the user previously saved outside the App, such as JSON backup files stored in the user's downloads folder or cloud storage.

If a user no longer has access to the App and needs help with data deletion, the user may contact Go Steko LLC at cheyton@gosteko.com for assistance. Go Steko LLC does not guarantee a response within any specific timeframe.

Go Steko LLC does not guarantee complete, full, or immediate deletion of locally stored data. Some data may persist in browser caches, backups, or exported files beyond Go Steko LLC's direct control. Data held by the user's browser or device is subject to the user's own retention settings and is outside Go Steko LLC's control.

7. Your Rights

Users have the following rights regarding their data stored in the App:

  • Access — export a copy of the data stored in the App using the "Export my data" feature in Settings.
  • Correction — edit or delete inaccurate or incomplete information directly within the App.
  • Deletion — clear locally stored data using the "Reset All Data" feature in Settings.
  • Withdraw consent — withdraw consent for data processing at any time by resetting all data or clearing the browser's site data.

To exercise any of these rights or ask questions, contact Go Steko LLC at cheyton@gosteko.com.
