STEKO — Privacy Policy

Last updated: August 10, 2026

1. Overview

Go Steko LLC ("Go Steko") operates the STEKO app, a free, installable web application (Progressive Web App) deployed at https://gosteko77.github.io/STEKO/. This Privacy Policy describes how Go Steko handles information in connection with the App. Much of this policy is written by AI with human adjustments and input. Therefore Go Steko LLC does not guarantee absolute validity of all statements in this policy.

2. No Account, No Sign-In

The App does not require and does not offer any account, login, registration, or sign-in mechanism. There are no user accounts, credentials, passwords, or authentication tokens. All data created in the App is stored locally on the user's device.

3. Information Go Steko Collects

Go Steko does not collect, receive, transmit, or store any personal data or user-created content from the App. The App does not send any data to any server controlled by Go Steko. There is no backend database, no cloud sync, and no server-side storage.

4. Information Stored Locally on the Device

The App stores the followimg data exclusively in the browser's local Storage on the user's device:

  • Goals (Summits): Name, purpose, term, deadline, priority, status, and other details the user enters.
  • Habits (Objectives): Title, associated summits, day-of-week schedule, and completion history.
  • Checkpoints: Milestone descriptions tied to each summit.
  • Progress logs: Daily self-rating scores (-5 to +5) per summit.
  • Values: Personal values the user selects or adds.
  • Settings: Theme mode (light/dark), accent color, onboarding completion state, and policy consent record.

This data never leaves the device. Go Steko has no access to it.

5. Service Worker and Caching

To enable offline use, the App installs a service worker that caches the App's own HTML, JavaScript, and image files in the browser. This cached data consists only of the App's static code and assets — it contains no user-created content or personal data. The cache can be cleared through the browser's site-data settings.

6. Data Export and Import

The App provides a manual export feature that creates a JSON file containing all locally stored data (goals, habits, checkpoints, logs, values, and settings). The user may save this file anywhere they choose. Importing reads a previously exported JSON file back into the App. The export and import operations happen entirely within the browser — the file is never uploaded to any server.

7. Reset All Data

The App provides a "Reset all data" function in Settings. When used, it deletes all locally stored data and preferences, including:

  • All summits, habits, checkpoints, progress logs, and values
  • Theme mode and accent color.
  • Onboarding completion state and policy consent record

After reset, the App returns to its initial state with default settings. No user data or preferences of any kind are retained. Exported JSON files saved outside the App (e.g., in Downloads or cloud storage) are not affected by the reset and remain wherever the user saved them.

Note: Resetting the App does not delete any exported JSON backup files the user previously saved outside the App (for example, in the Downloads folder or cloud storage). Those files remain wherever the user saved them and can be imported again if desired. To delete those, the user must remove them manually from their storage location.
Note: The service worker cache (the App's static code files) may remain in the browser after reset. This does not contain any user data — only the App's HTML, JavaScript, and image files. To clear it, use the browser's "Clear site data" or "Clear browsing data" settings for the site gosteko77.github.io.

8. Third-Party Services

The only third-party service involved in the App's operation is GitHub Pages, which hosts the App's static files. GitHub Pages is operated by GitHub, Inc. When a user visits the App URL, GitHub's servers deliver the static files to the browser. Go Steko does not control GitHub's logging or data practices. Users are encouraged to review GitHub's Privacy Policy at https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement.

9. Children's Privacy

The App is not directed to children under 13 and does not knowingly collect any information from anyone, including children.

10. Data Security

All data is stored locally in the browser. No method of local storage is completely secure. To the maximum extent permitted by law Go Steko is not liable for data loss, corruption, or unauthorized access to data stored on the user's device, including access by others who share the device or who gain physical or remote access to it. Users may use the export feature to maintain backups of important data.

11. Changes to This Policy

Go Steko may update this Privacy Policy from time to time. Changes will be posted on this page with a new "Last updated" date.

12. Contact
