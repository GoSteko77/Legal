STEKO — Reset All Data

Last updated: August 11, 2026

Overview

STEKO does not have user accounts. All data is stored locally on the user's device. The "Reset all data" function in Settings erases everything and returns the App to its initial state. Go Steko LLC does not guarantee absolute validity of the following statements as (besides this sentence) this page is written with AI.

How to Reset

  1. Open the App and tap the gear icon in the top-right corner of the dashboard.
  2. Scroll to the Data section.
  3. Tap "Reset all data".
  4. Confirm by tapping "Reset" in the dialog.

What Gets Deleted

The reset function deletes all locally stored data and preferences, with no exceptions:

  • All goals (summits) and their details
  • All habits (objectives) and completion history
  • All checkpoints
  • All progress logs and self-rating scores
  • All selected personal values
  • Theme mode (light/dark) — resets to default
  • Accent color — resets to default
  • Onboarding completion state
  • Privacy Policy and Terms of Service consent record

No user data or preferences of any kind are retained after reset. The App returns to its original default state, as if it had never been used.

Note: Resetting the App does not delete any exported JSON backup files the user previously saved outside the App (for example, in the Downloads folder or cloud storage). Those files remain wherever the user saved them and can be imported again if desired. To delete those, the user must remove them manually from their storage location.
Note: The service worker cache (the App's static code files) may remain in the browser after reset. This does not contain any user data — only the App's HTML, JavaScript, and image files. To clear it, use the browser's "Clear site data" or "Clear browsing data" settings for the site gosteko77.github.io.
